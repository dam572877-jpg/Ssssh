# Ahmed & Shahd — GitHub Pages

This is the **single-file, upload-ready** version of the website.

## Upload

1. Download and extract this ZIP.
2. Open the extracted folder.
3. Upload **all three items** directly to the root of your GitHub repository:
   - `index.html`
   - `README.md`
   - `.nojekyll`
4. On GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/(root)`, then click **Save**.
7. Wait for the deployment and open the URL shown in the Pages section.

## Why this version avoids broken photos

All five original photos are embedded inside `index.html` itself as image data. The favicon is embedded too. There is no `assets` folder, no external image URL, no external JavaScript/CSS library, no npm install, and no build step. This means you cannot accidentally forget to upload a photo folder or break a relative image path.
